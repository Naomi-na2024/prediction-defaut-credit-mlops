# CreditScore

Application de scoring crédit : à partir de la situation financière d'un client, elle estime sa
probabilité de défaut de paiement et lui attribue un score de 300 à 850 avec une note de A à D.

- **Évaluer un dossier** : un client à la fois, avec l'explication du score.
- **Évaluer un fichier** : un fichier Excel ou CSV de clients, noté en une fois.
- **API** : documentation sur `/docs`.

Projet de Naomi Nandjui. Code source : voir le dépôt GitHub du projet.
